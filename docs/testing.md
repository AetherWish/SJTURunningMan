# 测试指南

## 现状

| 平台 | 自动化测试 | 说明 |
| --- | --- | --- |
| 安卓 | ✅ 有 | 单元测试 + 仪器测试，见下 |
| 电脑版 | ❌ 无 | 目前只能手动验收 |
| iOS | ❌ 无 | 无测试 target |
| 鸿蒙 | ❌ 无 | 目前只能手动验收（见下） |

**补充测试是欢迎的** —— 新增测试的约定见 [CONTRIBUTING.md](../CONTRIBUTING.md)。

## 安卓

### 单元测试（不需要设备）

```bash
cd apps/android
./gradlew test
```

报告：`app/build/reports/tests/testDebugUnitTest/index.html`

现有用例：

| 文件 | 覆盖内容 |
| --- | --- |
| `app/src/test/java/com/sjtu/runner/data/DataGeneratorTest.kt` | 路线距离校正、截断模式达标、整圈模式、过长路线截断、配速钳制在规则范围内、payload 匹配上传 schema |
| `app/src/test/java/com/sjtu/runner/update/UpdateCheckerTest.kt` | 版本号解析（前缀 / 预发布）、新版本识别、旧版本与相等版本忽略 |

### 仪器测试（需要设备或模拟器）

```bash
cd apps/android
./gradlew connectedAndroidTest
```

用例：`app/src/androidTest/java/com/sjtu/runner/AppInstrumentedTest.kt`。

### 加一条测试

- 纯逻辑（数据生成、版本比较、坐标换算）→ 放 `app/src/test/`，用 JUnit 4；
- 需要 Context / UI 的 → 放 `app/src/androidTest/`，用 AndroidX JUnit + Espresso / Compose Test。

## 电脑版手动验收清单

改完电脑版代码，按下面逐项过一遍再提交：

**启动**

- [ ] `python qtui.py` 能起界面，无异常栈
- [ ] 承诺书弹窗出现，勾选后才能继续
- [ ] 背景图与主题正常（无花屏、无缺字）

**参数校验**

- [ ] 跑步次数输 `0` 或 `31` 被拒
- [ ] 时间输 `8:00`（非 `HH:MM:SS`）被拒
- [ ] 日期输 `2026/05/07` 被拒
- [ ] 距离输 `6` 被拒，输 `5` 通过

**路线**

- [ ] 「预设路线」下拉能选到 `default.txt`
- [ ] 「自定义...」能导入一个 txt，导入后出现在下拉里
- [ ] 重启程序后导入的路线仍在
- [ ] 滚轮划过下拉不会误切路线
- [ ] 「删除」能删掉导入的路线，但删不掉 `default.txt`

**预览**

- [ ] 「预览路线」在**未登录**状态下也能出图
- [ ] 浏览器打开的地图里有连线、绿起点、红终点
- [ ] 人为构造一条有 >150 m 跳段的路线，确认该段被标红

**上传**

- [ ] 1 次、2 km 的配置能跑完并显示成功
- [ ] 「停止任务」能中断，界面不卡死
- [ ] 日志区逐条输出，无未捕获异常

**打包**

- [ ] `python -m PyInstaller --clean --noconfirm ./main.spec` 成功
- [ ] 产物图标正确（不是 PyInstaller 默认图标）
- [ ] 产物能启动，`assets/` 资源正常加载

## 鸿蒙手动验收清单

改完鸿蒙端代码，先用 hvigor 编译一遍（见 [build.md](./build.md#鸿蒙)），再按下面逐项过一遍：

**启动与门禁**

- [ ] `assembleHap` 成功，安装后能正常启动，无 jscrash（重点：抛 `class constructor cannot called without 'new'` 说明有自定义组件被写在箭头函数里，见 [harmonyos.md](./harmonyos.md#8-已知的-arkts-工具链陷阱)）
- [ ] 首次进入出现「使用承诺书」全屏卡片，未勾选时「我承诺，进入软件」不可点
- [ ] 点「退出」应用直接结束；勾选同意后重启应用不再弹出

**登录**

- [ ] 首页没有底部页签，标题「开润」与右上角账号/关于两个图标按钮在同一行
- [ ] 点右上角账号图标（未登录显示「登录」）能进入登录页，Web 页正常加载并显示进度条
- [ ] 登录完成后自动返回，状态卡片显示「已登录，点击可退出」，账号图标文案变为「账号」
- [ ] 已登录时点账号图标弹出「退出账号」确认框，确认后回到未登录态
- [ ] 点右上角「关于」图标进入独立「关于」页

**参数配置**

- [ ] 跑步次数下拉框可选 1/3/5/7/10/15/30，选「自定义…」输入 `0` / `31` 会被钳制回 1–30 区间
- [ ] 选「自定义…」后下拉框内文字变为「自定义」，旁边出现次数输入框（不再显示「确定」以外的空按钮）
- [ ] 点按开始时间弹出 24 小时制时分秒选择器，改值后「确定」能回填（时上限 23、分秒上限 59）
- [ ] 点开始时间标签旁的「圈 i」图标能弹出随机波动规则说明
- [ ] 结束日期整行可点，弹出日期选择器，默认昨天
- [ ] 目标距离滑杆 1–5 km，数值紧贴「目标距离」标签右侧同一行并随拖动实时更新；顶部状态卡的「距离」以最终值为准
- [ ] 首页与关于页滚动时右侧出现滚动条，静止后淡出

**路线**

- [ ] 下拉能列出内置路线与自定义路线（含点数与「内置」标记）
- [ ] 点「设计新路线」进入地图页，连点采集后保存能回到主页并从 toast 看到点数
- [ ] 删除非内置路线会二次确认；内置路线不能删
- [ ] 「预览路线」在未登录时也能出图（散点 + 距离/点数/跳段数摘要）

**上传**

- [ ] 1 次、4 km 的配置能跑完并显示「任务完成: 成功 1 条，失败 0 条」
- [ ] 状态卡片阶段依次出现 准备中 → 获取认证 → 生成数据 → 上传中 → 已完成，进度条前进
- [ ] 任务进行中点「停止任务」能中断，界面不卡死
- [ ] 日志按等级着色（INFO/WARN/ERROR/SUCCESS），自动滚到底部，「清空」可用
- [ ] 所选路线超过目标距离时弹出「路线距离提醒」，三个按钮行为符合提示文案
- [ ] cookie 失效时出现顶部重新登录横幅，点「登录」能回到登录页

**关于与更新**

- [ ] 关于页显示版本号 `v4.5.0`、免责声明与项目信息（含「鸿蒙版维护：Github@AetherWish」）
- [ ] 进入关于页时内容不顶着返回栏：返回图标与「关于」标题下方留有安全区，首屏不被标题栏遮挡
- [ ] 点「检查更新」能返回「已是最新版本」或「发现新版本」，弱网下显示「检查更新失败：…」
- [ ] 「仓库」「水源」按钮能拉起浏览器

**主题**

- [ ] 系统切深色模式后，背景/卡片/文字对比正常，无白底黑字错配
